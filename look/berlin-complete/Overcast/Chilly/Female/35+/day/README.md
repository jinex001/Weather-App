# 여성 오버캐스트 에디토리알 · 제품 브레이크다운

베를린 · 30대 여성 · 구름 낀 낮 · 기온 12°C / 체감 9°C.
러닝 5개, 스트리트 5개, 미니멀 5개 착장과 총 91개 제품컷입니다.

## 폴더 구성
- editorial.png: 해당 착장 에디토리알 원본
- products/: 제품별 500×500 PNG, 위에서 수직으로 촬영한 플랫레이
- README.md: 화면용 제목, 카피, 제품 설명, 스타일링 팁 및 적용 지침
- products.json: 이미지 경로와 제품 정보, 표시 순서
- PROMPTS.md: 제작 프롬프트 기록

## Claude Code 적용
index.json으로 착장을 연결하고 각 폴더의 README.md와 products.json을 함께 읽으세요.
이미지 경로는 해당 착장 폴더 기준입니다. 제품은 products 배열 순서대로 보여주세요.
제품컷은 1:1 비율과 object-fit: contain을 사용하고 별도의 그림자를 추가하지 마세요.
실제 판매 상품 정보가 아닌 AI 스타일링 콘셉트입니다. 브랜드, 가격, 구매 링크, 소재 혼용률과 기능성 수치를 임의로 만들지 마세요.
가려진 부분을 재구성한 제품은 reconstruction 정보를 유지하세요. PROMPTS.md는 제작 기록이며 화면 카피로 표시하지 않습니다.
