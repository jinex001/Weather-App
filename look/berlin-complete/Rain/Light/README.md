# Light Rain - 가벼운 비

비 에디토리얼의 강수 강도별 보관 폴더.

경로: <체감온도 단계>/<성별>/<연령대>/<day|night>/<running|street|minimal>/<번호>/

- 번호는 스타일별 01, 02 순서로 증가한다.
- 각 룩은 editorial.jpg, products/ 아래 개별 아이템 이미지, products.json, README.md, PROMPTS.md로 구성한다.
- 에디토리얼은 한 장씩 사용자 승인을 받은 뒤에만 제품 컷 제작과 업로드를 진행한다.
- 강수량 수치나 날씨 API 매핑은 아직 미정이다.
- 기준: design/IMAGE_STYLE.md 및 design/look-library.md.
