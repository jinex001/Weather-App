Built-in image generation. Existing editorial reused as outfit reference, not regenerated. One call per item.

## Shared prompt

Use case: product-mockup. Input image is outfit reference. Create ONE independent square product photograph of ONLY the item described below. Match reference visible color, material appearance, silhouette, seams, zipper and construction without redesign. Hidden details must be conservative reconstructions. Warm ivory background near #F3EFE8, soft studio lighting, subtle contact shadow, full item centered with generous margins. Clothing: vertical overhead flat lay, no body inside. For shoes ONLY: matching pair resting on soles parallel side by side, both toes toward top, camera vertically overhead. For paired accessories only one matching pair. No other item categories, person, hands, mannequin, hanger, text, logos, watermark, grid, collage or multi-item board.
