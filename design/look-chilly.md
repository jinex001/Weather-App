# CHILLY · 쌀쌀함 · 체감 1~9°C · 가을 · 30~40대

앱 문구는 index.html `CHILLY`(한국어·영어·독일어). 사진은 `look/chilly/<run|street|minimal>-<m|f>.jpg`, 아이템 사진 `-p1~6.jpg`.

베를린 가을 기준이에요. 아침저녁은 0°C 가까이 내려가고 바람과 비가 잦아서, 얇은 옷을 여러 겹 입고 겉옷은 바람과 물을 막는 것으로 정했어요.

## 1. 러닝 / 운동

**한 줄 요약:** 출발할 때 살짝 춥게 입으세요. 10분 뛰면 체감이 10°C쯤 올라가요.

| | 남성 | 여성 |
|---|---|---|
| **아우터** | 가벼운 방풍 러닝 재킷. 지퍼를 끝까지 올리고, 반사 디테일이 있는 것 | 허리가 짧은 방풍 재킷이나 가벼운 패딩 조끼, 반사 디테일 |
| **상의** | 긴팔 기능성 티(드라이핏·메리노) 한 겹. 5°C 아래면 하프집 미드레이어를 더함 | 긴팔 기능성 티 또는 썸홀 있는 하프집. 안에 스포츠 브라 |
| **하의** | 기모 러닝 타이츠, 또는 타이츠 위에 쇼츠 | 하이웨이스트 기모 레깅스 |
| **신발** | 쿠션 러닝화. 비 오면 GTX(방수) 러닝화 | 쿠션 러닝화. 젖은 낙엽길이면 접지력 좋은 트레일 러닝화 |
| **양말** | 메리노 러닝 양말(크루 길이, 발목 덮게) | 메리노 러닝 양말(크루 길이) |
| **소품** | 얇은 러닝 장갑, 귀를 덮는 헤어밴드나 비니 | 얇은 장갑, 귀를 덮는 헤어밴드, 넥워머 |

## 2. 스트리트웨어

**한 줄 요약:** 후디를 겹치고 그 위에 짧은 아우터. 품은 넉넉하게.

| | 남성 | 여성 |
|---|---|---|
| **아우터** | 숏 패딩, 코치 재킷, 워크 재킷(초어·카코트) 중 하나 | 크롭 패딩, 오버핏 봄버, 퀼팅 재킷 |
| **상의** | 헤비 후디나 스웻셔츠. 안에 롱슬리브 티 | 오버핏 후디나 하프집 스웻. 안에 슬림 롱슬리브나 탱크 |
| **하의** | 와이드 데님, 카고 팬츠, 나일론 파라슈트 팬츠 | 와이드·배기 데님, 카고 팬츠, 트랙 팬츠 |
| **신발** | 하이탑이나 청키 스니커즈. 비 오면 워크 부츠 | 청키 스니커즈, 플랫폼 스니커즈, 첼시 부츠 |
| **양말** | 두툼한 화이트·그레이 크루삭스(보이게 신기) | 크루삭스나 립 니삭스 |
| **소품** | 비니나 볼캡, 크로스백, 넥워머 | 비니, 버킷햇, 숄더백, 머플러 |

## 3. 미니멀

**한 줄 요약:** 니트 하나에 코트. 무채색과 어스톤 두세 가지 색으로만.

| | 남성 | 여성 |
|---|---|---|
| **아우터** | 울 싱글 코트(차콜·네이비·카멜), 또는 맥 코트(방수 트렌치) | 롱 울 코트나 트렌치 코트(베이지·블랙·초콜릿) |
| **상의** | 메리노·캐시미어 크루넥이나 터틀넥 니트. 안에 무지 티 | 파인게이지 터틀넥, 라운드 니트, 니트 위에 셔츠 레이어드 |
| **하의** | 울 슬랙스, 스트레이트 치노, 생지 데님 | 와이드 울 팬츠. 롱 니트 스커트에는 불투명 타이츠 |
| **신발** | 가죽 더비, 첼시 부츠, 미니멀 레더 스니커즈 | 앵클 부츠, 로퍼, 미니멀 레더 스니커즈 |
| **양말** | 울 혼방 드레스 삭스(바지나 신발과 같은 색) | 울 양말, 스커트일 때는 60~80데니어 타이츠 |
| **소품** | 캐시미어 머플러, 가죽 장갑, 토트백 | 울 머플러나 스카프, 가죽 장갑, 미니멀 숄더백 |

## 공통 팁 (CHILLY)

- **아침 vs 낮:** 일교차가 6~8°C라서, 벗어서 들고 다닐 수 있는 한 겹(니트·후디·미드레이어)을 꼭 넣으세요.
- **비:** 베를린 가을비는 우산보다 후드 달린 방수 아우터(맥 코트, 방수 쉘)가 편해요.
- **바람 30km/h 이상:** 니트만으로는 바람이 뚫고 들어와요. 겉옷을 방풍 소재로 바꾸세요.
- **소품 하나:** 머플러나 비니 하나로 체감이 2~3°C 올라가요.
