# COLD · 추움 · 체감 -9~0°C · 겨울 초입 · 30~40대

앱 문구는 index.html `STYLE_TEXT.cold`(한국어·영어·독일어). 사진은 `look/cold/<run|street|minimal>-m.jpg`(스트리트는 `street-m-2.jpg`가 하나 더, 이틀씩 번갈아). 남성만 있음. 여성은 기본 추움 문구(`LOOK.cold`)와 시트에서 자른 사진.

## 1. 러닝 / 운동

**한 줄 요약:** 긴 타이츠에 기모 긴팔 + 바람막이. 비니·장갑은 꼭.

| | 남성 |
|---|---|
| **아우터** | 후드 달린 바람막이. 0° 아래면 안에 얇은 경량 패딩 조끼 |
| **상의** | 기모 하프집 긴팔 + 안에 기능성 이너 |
| **하의** | 긴 러닝 타이츠 + 위에 러닝 쇼츠 |
| **신발** | 쿠션 러닝화. 서리 낀 길은 접지력 좋은 밑창으로 |
| **양말** | 발목 위로 올라오는 두툼한 러닝 양말 |
| **소품** | 러닝 비니, 터치되는 러닝 장갑, 맑은 날엔 선글라스 |

## 2. 스트리트웨어

**한 줄 요약:** 두꺼운 후디 위에 패딩 점퍼. 목도리 하나 두르세요.

사진 두 장(블랙 패딩 + 그레이 후디 + 블랙 카고 / 그린 점퍼 + 크림 후디 + 베이지 카고 + 머플러)에 같은 문구.

| | 남성 |
|---|---|
| **아우터** | 오버핏 패딩이나 충전재 들어간 점퍼(블랙·카키) |
| **상의** | 두꺼운 기모 후디(그레이·크림) + 안에 흰 롱슬리브 티 |
| **하의** | 와이드 카고 팬츠(블랙·베이지). 0° 가까우면 안에 히트텍 |
| **신발** | 청키 러닝 스니커즈(그레이·크림) |
| **양말** | 두꺼운 화이트 크루삭스 |
| **소품** | 울 머플러, 백팩, 맑은 날엔 선글라스 |

## 3. 미니멀

**한 줄 요약:** 터틀넥 위에 롱 울 코트. 머플러는 길게 늘어뜨려요.

| | 남성 |
|---|---|
| **아우터** | 두꺼운 롱 울 코트(블랙·차콜) |
| **상의** | 두꺼운 울 터틀넥(블랙) |
| **하의** | 주름 잡힌 울 슬랙스(차콜) |
| **신발** | 밑창 두꺼운 가죽 첼시 부츠 |
| **양말** | 두꺼운 울 양말(다크) |
| **소품** | 길고 두툼한 울 머플러(그레이), 가죽 장갑, 맑은 날엔 선글라스 |
