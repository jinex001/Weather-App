# COOL · 체감 10~17°C · 가을 · 30~40대

## 러닝 / 운동

**한 줄 요약:** 반팔에 얇은 긴팔 하나. 5분 뛰면 반팔 날씨예요.

| | 남성 | 여성 |
|---|---|---|
| **아우터** | 얇은 패커블 바람막이. 뛰다가 벗어 허리에 묶을 수 있는 것 | 얇은 패커블 바람막이나 러닝 베스트 |
| **상의** | 반팔 기능성 티 + 얇은 긴팔 레이어. 15° 넘으면 반팔만 | 반팔 기능성 티 + 얇은 긴팔 하프집. 안에 스포츠 브라 |
| **하의** | 러닝 쇼츠 + 얇은 타이츠, 또는 7부 타이츠 | 하이웨이스트 레깅스나 7부 레깅스. 위에 쇼츠도 좋아요 |
| **신발** | 쿠션 러닝화. 젖은 길이면 밑창 접지력 확인 | 쿠션 러닝화. 젖은 길이면 밑창 접지력 확인 |
| **양말** | 얇은 기능성 러닝 양말(발목 위) | 얇은 기능성 러닝 양말(발목 위) |
| **소품** | 얇은 비니나 헤어밴드. 10~12°면 얇은 장갑도 | 헤어밴드나 캡. 10~12°면 얇은 장갑도 |

스트리트웨어·미니멀은 아직 단계 공통 문구(index.html `LOOK.cool`)를 씁니다.
