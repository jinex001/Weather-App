# COOL · 선선함 · 체감 10~17°C · 가을 · 30~40대

앱 문구는 index.html `STYLE_TEXT.cool`(한국어·영어·독일어). 사진은 `look/cool/<run|street|minimal>-<m|f>.jpg`.

## 1. 러닝 / 운동

**한 줄 요약:** 반팔에 얇은 긴팔 하나. 5분 뛰면 반팔 날씨예요.

| | 남성 | 여성 |
|---|---|---|
| **아우터** | 얇은 패커블 바람막이. 뛰다가 벗어 허리에 묶을 수 있는 것 | 얇은 패커블 바람막이나 러닝 베스트 |
| **상의** | 반팔 기능성 티 + 얇은 긴팔 레이어. 15° 넘으면 반팔만 | 반팔 기능성 티 + 얇은 긴팔 하프집. 안에 스포츠 브라 |
| **하의** | 러닝 쇼츠 + 얇은 타이츠, 또는 7부 타이츠 | 하이웨이스트 레깅스나 7부 레깅스. 위에 쇼츠도 좋아요 |
| **신발** | 쿠션 러닝화. 젖은 길이면 밑창 접지력 확인 | 쿠션 러닝화. 젖은 길이면 밑창 접지력 확인 |
| **양말** | 얇은 기능성 러닝 양말(발목 위) | 얇은 기능성 러닝 양말(발목 위) |
| **소품** | 얇은 비니나 헤어밴드. 10~12°면 얇은 장갑도 | 헤어밴드나 캡. 10~12°면 얇은 장갑도 |

## 2. 스트리트웨어

**한 줄 요약:** 후디나 니트에 가벼운 아우터. 낮엔 벗어서 들고 다니세요.

| | 남성 | 여성 |
|---|---|---|
| **아우터** | 가벼운 나일론 재킷이나 코치 재킷, 오버핏 셔켓 | 가벼운 재킷이나 셔켓. 따뜻해지면 벗어서 들고 |
| **상의** | 그레이 후디 + 안에 흰 롱슬리브 티 | 오버핏 니트나 스웻 + 밑단으로 보이는 흰 티 |
| **하의** | 와이드 카고 팬츠나 나일론 파라슈트 팬츠 | 와이드 카고 팬츠나 배기 데님 |
| **신발** | 청키 러닝 스니커즈(그레이·실버) | 청키 스니커즈 |
| **양말** | 화이트 크루삭스 | 화이트 크루삭스 |
| **소품** | 볼캡, 백팩이나 크로스백 | 큰 숄더백. 바람 불면 볼캡 |

## 3. 미니멀

**한 줄 요약:** 니트 위에 얇은 코트 하나. 머플러로 온도 조절.

| | 남성 | 여성 |
|---|---|---|
| **아우터** | 얇은 울 코트나 맥 코트(차콜·블랙) | 오버핏 롱 울 코트(블랙·차콜) |
| **상의** | 크루넥 울 니트 + 안에 흰 티 | 크롭 울 니트 + 밑단으로 보이는 흰 티 |
| **하의** | 주름 잡힌 와이드 울 슬랙스 | 와이드 울 팬츠 |
| **신발** | 가죽 더비나 로퍼 | 굽 낮은 앵클 부츠, 로퍼나 미니멀 스니커즈 |
| **양말** | 울 혼방 다크 삭스 | 울 양말(바지와 같은 색) |
| **소품** | 얇은 울 머플러, 가죽 토트백 | 큰 숄더백, 얇은 머플러 |
